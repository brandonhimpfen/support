# Support & Contribute to Brandon Himpfen’s Open Work

This repository is a central hub for supporting, contributing to, and engaging with Brandon Himpfen’s work across open source, datasets, writing, and systems.

The focus is on building open knowledge, practical tools, and long-term digital infrastructure that others can use, learn from, and build upon.

## 💡 Ways to Support

### 💛 Free Support

You can support the work without spending anything:

- ⭐ Star repositories you find useful  
- 🔁 Share projects with others  
- 🐛 Open issues and suggest improvements  
- 🧠 Provide feedback and ideas  

### 💼 Financial Support

If you find value in the work and want to support it directly:

- 💖 GitHub Sponsors: https://github.com/sponsors/brandonhimpfen  
- 🌐 Website Memberships (The Desk, The Waypoint, The Signal): https://www.brandonhimpfen.com/#/portal/signup  

GitHub Sponsors tiers are already structured and provide different levels of access and support options.

### 📢 Sponsorship & Visibility

For individuals and organizations looking to support more deeply:

Sponsorship may include:

- Visibility in relevant projects or ecosystems  
- Mentions in curated resources (where appropriate)  
- Participation in the broader open work ecosystem  

All visibility is curated, relevance-based and aligned with project integrity.  

This is not a pay-for-placement system.

## 🚀 Sponsorship Tiers

All sponsorship tiers are managed via GitHub Sponsors:

👉 https://github.com/sponsors/brandonhimpfen

Each tier supports:

- Open source development  
- Dataset creation and maintenance  
- Writing and research  
- Long-term infrastructure projects  

Higher tiers may include additional visibility or engagement opportunities, depending on fit and relevance.

## 🛠️ Contribute

Contributions are welcome across projects.

Ways to contribute:

- Submit pull requests  
- Suggest new ideas or datasets  
- Improve documentation  
- Report issues  

Each repository may have its own contribution guidelines.
